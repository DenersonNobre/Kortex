# kortex_br

Pure Dart Brazilian validators, formatters, and normalizers for Kortex (`sdk: dart`, zero external dependencies).

## Included
- `CpfValidator` / `CpfFormatter`
- `CnpjValidator` / `CnpjFormatter`
- `CepValidator` / `CepFormatter`
- `PhoneBrValidator` / `PhoneBrFormatter`
- `BrlCurrencyFormatter` (`formatCents` / `parseToCents`)
- `PixKeyValidator`
- `MercosulPlateValidator`
- `digitsOnly` / `unmask`
