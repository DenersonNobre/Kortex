# Changelog — kortex_cli

## [0.1.0] - 2026-11-27

### Added
- `kortex create <app_name>` para scaffolding da estrutura base (`main.dart`, `app/`, `app/routes/`).
- `kortex module <module_name>` para scaffolding de fatia vertical (`domain/`, `data/`, `features/`, `ui/` com `StatelessWidget` + `IKortexController` + `KortexScope`).
